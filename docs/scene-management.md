# 場景管理

Tomoshibi 的場景層位於 Live2D 人物與舞台特效後方。它保留原本的背景圖片／攝影機功能，並新增可重複使用的 2D、影片與 3D 場景。

## 支援格式

| 場景種類 | 本機檔案 | 網址 |
| --- | --- | --- |
| 2D 圖片 | JPG、PNG、GIF、WebP、AVIF | 瀏覽器可顯示的圖片 URL |
| 2D 影片 | MP4、WebM、MOV、M4V、OGV | 瀏覽器可播放的影片 URL |
| 2D 模型 | 從 `live2d-models/` 選擇 | Cubism `.model3.json` URL |
| 3D 場景 | GLB | GLB 或完整的 GLTF URL |

本機 3D 場景只接受 GLB。GLTF 經常依賴另外的 `.bin` 與貼圖檔，單獨選取 `.gltf` 無法保證資源完整；網址模式則可使用 GLTF，但來源伺服器必須提供所有相依檔並允許 CORS。

2D 模型使用現有的 Cubism runtime。它與人物共用一個 WebGL context，但持有獨立的模型、待機動作、眨眼、呼吸與物理狀態；場景模型固定先繪製，人物再繪製，因此不會蓋住人物。模型資料夾包含的 MOC、貼圖、動作、物理與姿勢檔仍由 `.model3.json` 管理。

## 使用方式

1. 打開「設定 → 場景」。
2. 新增 2D 圖片、2D 影片、2D 模型或 3D 場景。
3. 選擇本機素材，或輸入素材 URL。
4. 調整填滿方式、透明度與淡入時間。3D 場景另可調整相機、燈光、背景色與自動旋轉。
5. 按「套用」切換目前場景。

2D 模型可以直接選擇 `live2d-models/` 中已安裝的模型，或輸入完整 `.model3.json` URL，並調整縮放、水平／垂直位置及指標視差。人物切換導致 Cubism runtime 重建時，場景模型會自動重新掛載。

「目前背景」是內建場景，會沿用「常規」分頁中的背景圖片或攝影機背景，舊設定不需要搬移。

## 與演出搭配

在「設定 → 演出」選擇任一演出方案後，可指定「演出搭配場景」：

- 開啟「演出結束後恢復原場景」：只在演出時間軸期間暫時切換。
- 關閉：演出開始時切換，結束後持續使用該場景。

條件播放、隨機播放或 AI 導演最後都是選出一套演出方案，因此會自動套用該方案綁定的場景。

## 儲存與效能

- 場景設定與演出綁定存在瀏覽器的 `localStorage`。
- 本機圖片、影片與 GLB 存在獨立的 IndexedDB `tomoshibi-scene-assets`，不會塞進 `localStorage`。
- 3D 場景使用 Three.js 與 WebGL，像素比上限為 2。GLTF 內建動畫會自動播放。
- 刪除場景時，其 IndexedDB 素材與相關演出綁定也會移除。
- 遠端 URL 必須保持可存取；若來源有 CORS、憑證或檔案遺失問題，場景會退回目前背景。
