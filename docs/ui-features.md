# Tomoshibi UI 功能盤點

> 依據 `frontend-src/`（源碼）盤點，非 `frontend/`（產物）。每一項都是實際渲染出來的控制項，不是從翻譯鍵推測的。
> 對應版本：`main` @ 2026-07-31（2e 設定抽屜一致性合入後）

---

## 一、設定抽屜（11 個分頁）

抽屜底部只有一顆「關閉」。四個分頁有自己的「套用／還原」，其餘七個是點下去就即時打 API。

### 1. general 一般

| 控制項 | 說明 |
|---|---|
| 語言切換 | English／中文，選了立刻套用 |
| 使用鏡頭作為背景 | 開關；失敗會自動退回關閉 |
| 顯示字幕 | 開關，控制畫布上的 AI 回覆字幕 |
| 背景圖片 | 下拉選單，列出 `backgrounds/` 內的檔案 |
| 自訂背景網址 | 文字輸入，優先權高於下拉選單 |
| 角色預設 | 下拉選單，選了立即切換角色 |
| WebSocket URL / Base URL | 文字輸入 |
| 圖片壓縮品質 | 0.1–1.0，供視覺輸入前處理 |
| 圖片最大寬度 | 數字輸入 |
| 套用／還原 | 見下方「存檔機制」說明 |

### 2. characters 角色

角色清單（基底角色標記且不可刪）｜新增角色（名稱、人格 prompt、Live2D 外觀、聲音、slug、AI 顯示名稱、頭像上傳）｜編輯角色｜語音試聽（12 秒逾時）｜刪除角色（二次確認，明示「不會刪記憶」）｜重新整理

### 3. personas 人設

角色預設人設（一鍵重設回預設）｜Persona 清單（套用／編輯／刪除；使用中的不可刪）｜新增 Persona（名稱、prompt、自訂 ID）｜編輯 Persona（編到生效中那個，存檔後自動重新套用）

### 4. llm 模型

三種模式共用一份表單（與首次啟動精靈相同）：

- **API Key** — OpenAI／Claude／Gemini＋金鑰＋模型名，附推理模型警語
- **Ollama** — 自動探測本機模型，探不到改手動輸入，有重試鍵
- **自訂端點** — Base URL＋模型＋金鑰

Test & Save；存檔後固定顯示「需重啟後端才生效」（後端只在啟動時讀一次 `conf.yaml`）。

### 5. live2d

指標互動開關｜滾輪縮放開關｜套用／還原

### 6. asr 識別

**上半（前端 VAD，存 `localStorage`）**：語音打斷｜對話結束後自動開麥｜連線後自動開麥｜語音起始閾值｜語音結束閾值｜靜音緩衝幀數｜**套用／還原**

**下半（後端引擎）**：

| 引擎 | 行為 |
|---|---|
| `sherpa_onnx_asr` / `faster_whisper` | 選了立即生效 |
| `groq_whisper_asr` / `azure_asr` | 選了**只當草稿**（橘字提示尚未儲存），要連同憑證一起送 |

Groq API Key＋儲存｜Azure API Key＋Region＋儲存（Region 空白會被擋下）

### 7. tts 合成

引擎下拉（`edge_tts` 免設定即時生效／`gpt_sovits_tts` 需先填欄位）｜GPT-SoVITS API URL｜參考音檔路徑｜儲存

### 8. agent 代理

允許主動搭話｜閒置幾秒後主動搭話（開啟時才顯示）｜允許按鈕觸發搭話｜套用／還原

### 9. memory 記憶

啟用長期記憶｜核心記憶字數上限 500–8000（草稿＋儲存）

**進階（預設收合）**：手動編輯核心記憶全文（整份覆寫，需二次確認）｜深度回想 FTS 開關｜FTS Top-K 1–10＋索引狀態｜重建索引（二次確認）｜清除記憶（二次確認，不可逆）

### 10. perf 效能

一鍵效能模式 light／standard／high（二次確認，原子寫入六個設定）｜模型保留時間三選一（永久常駐／立即卸載即時生效；自訂秒數需按儲存）｜記憶整理頻率 1／3／5 輪

### 11. about 關於

純展示：版本號（**寫死 `1.2.1`**）、GitHub、文件、授權條款。唯一沒有任何設定控制的分頁。

## 二、側邊欄

收合／展開｜開啟設定｜群組管理｜歷史紀錄｜新建對話（先存檔再開新的）｜**模式選單**（Live Mode／Pet Mode；瀏覽器版 Pet Mode 為 disabled 並附 tooltip）

| 面板 | 功能 |
|---|---|
| 對話面板 | 訊息串、頭像氣泡、**工具呼叫狀態指示**（執行中 spinner／完成勾／失敗叉）；頭像載入失敗退回姓名首字母 |
| 歷史抽屜 | 依最後訊息時間排序、點擊載入、單筆刪除（正在看的那筆禁刪） |
| 群組抽屜 | 顯示自己 UUID＋一鍵複製｜以 UUID 邀請｜成員清單（群主可踢人／自己可離開） |
| 相機面板 | 點一下開關前鏡頭，LIVE 紅點，權限錯誤顯示紅字。**與 general 的「鏡頭當背景」是兩路獨立串流**（一個給 AI 看，一個當背景） |
| 螢幕面板 | 螢幕分享開關，行為同上 |
| 瀏覽器面板 | 純被動顯示 agent 開啟的瀏覽器 session（iframe），**本身零控制項** |

## 三、輸入列

**Window 模式 footer** — AI 狀態文字｜麥克風開關（綠／紅）｜舉手／打斷（AI 說話中＝打斷；否則＝主動搭話訊號，受 agent 分頁開關控制）｜訊息輸入框（支援 IME 組字、Enter 送出）｜收合展開｜**附件（迴紋針）按鈕 — 有畫出來但沒接任何 onClick，點了完全沒反應**

**Pet 模式懸浮字幕條** — 關閉鍵｜最新一句 AI 訊息｜狀態文字｜麥克風／打斷｜輸入框＋明確的送出鍵｜**整條可拖曳**

## 四、Live2D 舞台

模型渲染與動態切換｜**拖曳移動模型**（>5px 判定）｜**點擊觸發 tap motion**（<200ms 且位移<5px；動作表由後端角色設定提供，前端無編輯入口）｜idle 時自動重置表情｜Pet 模式右鍵選單｜Pet 模式滑鼠穿透判斷｜背景（鏡頭串流水平鏡像／靜態圖）｜字幕｜**連線狀態色塊，斷線時可點擊手動重連**

另有開發後門：`window.Live2DDebug`（`playMotion`／`playRandomMotion`／`getMotionInfo`／`help`）掛在全域，任何人開 devtools 都能用。

## 五、只有桌面版有、瀏覽器版沒有的

1. **Pet 模式** — 極簡懸浮層，只有 Live2D＋字幕條，完全不顯示側邊欄／footer／標題列
2. **系統匣選單** — 模式切換、滑鼠穿透、顯示／隱藏視窗、結束
3. **Live2D 右鍵選單**（Pet 模式）— 麥克風、打斷、滑鼠穿透、滾輪縮放、字幕條開關、模式切換、**切換角色子選單**、隱藏、結束
4. **視窗控制列** — Windows／Linux 自繪三鍵；macOS 交給系統紅綠燈
5. **滑鼠穿透**
6. **拖曳懸浮字幕條**

瀏覽器版建置（`build:web`）因 `window.api` 不存在，這些 UI 分支會被跳過，不會出現任何按鈕。

## 六、存檔機制

**需要按分頁自帶「套用／還原」才會固定下來，否則關閉抽屜會復原：**
`general`（變更本身即時生效於畫面，是否保留取決於套用）｜`live2d`（同上）｜`agent`｜`asr` 上半部

四條關閉路徑（X 鍵、Esc、點背景、底部關閉）行為一致，都會還原未套用的即時預覽。

**點下去就立即打 API，抽屜關閉鍵對它們無效：**
`characters`｜`personas`｜`llm`（存檔成功仍需**重啟後端**）｜`asr` 下半部｜`tts`｜`memory`｜`perf`

多處（asr／tts／perf／memory／llm）存檔成功後會提示「需要重啟後端才會生效」——因為後端只在啟動時讀取一次 `conf.yaml`，前端誠實揭露了這個限制。
