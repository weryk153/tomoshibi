# Tomoshibi UI 功能盤點

> 依據 `frontend-src/`（源碼）盤點，非 `frontend/`（產物）。每一項都是實際渲染出來的控制項，不是從翻譯鍵推測的。
> 對應版本：`main` @ 2026-10-05（1.3.0，設定抽屜收成七個分頁之後）

---

## 一、設定抽屜（7 個分頁）

分頁順序與標籤在 `components/sidebar/setting/settings-tabs.ts`，每頁內容在 `setting-ui.tsx`。跟角色走的設定只在「角色」頁；其他分頁只放跟角色無關的。

控制項大多改了就存，沒有「套用／還原」；少數要按按鈕，見「存檔機制」。抽屜底部只有一顆「關閉」。寫進設定檔、要重新載入才生效的變更，會集中顯示在抽屜頂端（見「存檔機制」）。

### 1. 角色

左邊是角色清單：新增角色（在最上面）｜重新整理｜每個角色一列，正在用的標「使用中」。

右邊是選中角色的設定。頂端有角色名稱、「切換」（不是正在用的才有）、「刪除」（預設角色沒有；要再按一次確定，說明「它的記憶與聊天紀錄會保留」）。底下分六區：

| 區塊 | 控制項 |
|---|---|
| 基本 | 顯示名稱｜人設提示｜可以寫動作描寫（開關）｜AI 顯示名稱｜AI 頭像（上傳／清除） |
| 人設版本 | 人設清單（套用／編輯／刪除）｜新增人設（名稱、人設提示、選填 ID）｜使用角色原本人設。人設是共用的，每個角色各自選一個 |
| 外觀 | 外觀（角色模型）下拉，Live2D 與 VRM 模型都列在這裡｜動作清單：Live2D 是動作關鍵字、點擊區域指派、表情與情緒關鍵字；VRM 是動作關鍵字與顯示名稱、表情與情緒關鍵字。可試播，套用到用這個模型的所有角色 |
| 聲音 | 語音合成引擎（Edge TTS／GPT-SoVITS／跟底稿角色一樣）。選 Edge TTS 時：聲音、試聽、顯示全部語音。選 GPT-SoVITS 時：參考音檔、參考音逐字稿、參考音語言 |
| 語言 | 回覆語言｜發聲語言｜字幕翻成你看的語言（開關） |
| 記憶 | 開啟長期記憶（開關）。只有正在用的角色才顯示記憶內容：進階（手動編輯）裡可以改、清除「她自己」與「這段對話」的記憶 |

新增角色是表單：名稱、人設提示、外觀、聲音相關欄位、回覆語言、ID（選填）、AI 顯示名稱與頭像，按「儲存」才建立。

### 2. 對話

- **主動發言**：允許AI主動發言｜空閒多少秒後AI可發言｜通過舉手按鈕提示AI發言
- **她主動聊什麼**：主題清單（新增／刪除，附快速加入建議）｜自動抓網路新聞（開關）｜更新間隔（小時）｜立即更新
- **你（我的暱稱與頭像）**：我的暱稱｜選擇／清除頭像（存在瀏覽器 localStorage）
- **閱讀／玩家語言**｜**關於你（全域指示）**｜目前角色的發聲語言（唯讀，要改到「角色」頁）
- **用其他語言發聲**：翻譯方式（用你現在的 AI 翻譯／DeepLX）｜DeepLX 位址（選 DeepLX 才有）｜測試翻譯

### 3. 舞台

- **字幕與音量**：顯示字幕｜語音音量（0–500%）
- **場景管理**：新增 2D 圖片／2D 影片／2D 模型／3D 場景／攝影機｜場景清單（套用）｜選中場景的名稱、種類、本機素材或素材網址、內建背景（2D 圖片才有，列出伺服器上 `backgrounds/` 的圖）、各種類自己的參數｜刪除。背景只由場景決定
- **演出方案管理**：使用情境、播放池、選擇方式、試播、複製新增與編輯方案
- **特效演出**：試播小型點綴／人物登場／電影式特效｜目前人物的登場配樂（上傳／移除）
- **畫布互動**：滑鼠互動｜啟用滾輪縮放｜視線跟隨游標。Live2D 與 VRM 都適用

### 4. 直播

舞台頁網址（貼到 OBS）｜直播影片網址｜黑名單｜冷場秒數｜開始直播／停止｜狀態（舞台頁、聊天室、讀到／丟掉／排隊則數、正在回的留言、最近的錯誤）

### 5. 模型

- **語言模型**：來源四選一（這台電腦上的模型／貼上 API 金鑰／使用本機 Ollama／自訂端點（進階）），最上面寫目前在用什麼｜測試並儲存。存好會請後端重讀設定，不用重啟
- **背景工作與工具**：啟用網路搜尋／工具（實驗）｜背景工作的端點｜背景工作的模型
- **語音辨識**：上半是麥克風與語音偵測（只存在這個瀏覽器）：麥克風模式、進階個別開關、三個 VAD 數值。下半是辨識引擎：sherpa-onnx／faster-whisper 選了就存；Groq／Azure 先當草稿，連同金鑰按「儲存」才切換
- **語音合成引擎（TTS）**：一鍵安裝 GPT-SoVITS（支援的平台、還沒裝時才顯示）｜GPT-SoVITS 服務位址。誰用哪個引擎、哪段參考音，在「角色」頁設定

### 6. 效能

一鍵效能模式（輕量／標準／高效能，選了就套用，數字對不上時顯示「自訂」）｜背景工作頻率：情緒、記憶、她自己的事、目標、反思每幾輪跑一次，放在心上的目標與想法數量

### 7. 系統

介面語言｜連線設定（WebSocket 位址、伺服器位址，按「連線」才生效）｜圖片壓縮品質｜圖片最大寬度｜**遠端連線**：允許區網連線（開關，要重新啟動後端）、可連線網址清單（複製、QR code）｜**關於**：版本號（建置時從 `package.json` 帶入）、GitHub、文件、授權條款

## 五、只有桌面版有、瀏覽器版沒有的

1. **Pet 模式** — 極簡懸浮層，只有 Live2D＋字幕條，完全不顯示側邊欄／footer／標題列
2. **系統匣選單** — 模式切換、滑鼠穿透、顯示／隱藏視窗、結束
3. **Live2D 右鍵選單**（Pet 模式）— 麥克風、打斷、滑鼠穿透、滾輪縮放、字幕條開關、模式切換、**切換角色子選單**、隱藏、結束
4. **視窗控制列** — Windows／Linux 自繪三鍵；macOS 交給系統紅綠燈
5. **滑鼠穿透**
6. **拖曳懸浮字幕條**

瀏覽器版建置（`build:web`）因 `window.api` 不存在，這些 UI 分支會被跳過，不會出現任何按鈕。

## 六、存檔機制

**改了就存。** 開關與下拉選了就存；文字與數字欄位停手 0.8 秒或離開欄位才存，打到一半的值不存。欄位下方的小字會寫存了沒、或為什麼沒存。

**要按按鈕才存的只有這幾個**：
- 「系統」頁的連線位址：按「連線」才生效，關掉抽屜會丟掉沒按「連線」的草稿
- 「模型」頁的語言模型：按「測試並儲存」
- 「模型」頁的 Groq／Azure 辨識引擎：連同金鑰按「儲存」
- 新增角色：必填齊了按「儲存」

**還沒生效的變更集中在抽屜頂端。** 寫進設定檔、要後端重讀才生效的（例如閱讀語言、關於你、翻譯方式、網路搜尋工具、背景工作、語音辨識、語音合成服務、效能模式、正在用的角色），頂端會寫「有 N 項變更還沒生效」，按「重新載入」一次套用。直播中不能重新載入。「允許區網連線」要重新啟動後端：按鈕會換成「重新啟動後端」，桌面版由 App 自己重啟，網頁版顯示終端機指令。

語言模型例外：存好就請後端重讀設定，不進這個清單。

## 八、以前沒有 UI 的端點（現況）

| 功能 | 端點 | 現在在哪 |
|---|---|---|
| 主動話題清單／新聞抓取 | `GET`/`POST /api/proactive-topics`、`POST /api/proactive-topics/refresh` | 「對話」頁的「她主動聊什麼」（後端也收 `/refresh-now`，前端打的是 `/refresh`） |
| 遠端連線資訊（LAN／Tailscale／HTTPS 網址） | `GET /api/network-info`、`POST /api/network/host` | 「系統」頁的遠端連線，含「允許區網連線」開關 |
| MCP 工具開關 | `GET`/`POST /api/agent-config/use-mcpp` | 「模型」頁的「啟用網路搜尋／工具（實驗）」 |
| 玩家語言 | `GET`/`POST /api/player-language` | 「對話」頁的「閱讀／玩家語言」 |
| 關於你（全域指示） | `GET`/`POST /api/player-prompt` | 「對話」頁的「關於你（全域指示）」 |

背景圖片上傳（以前的 `POST /api/background`）已經拿掉：背景併進場景之後，自己的圖片影片用場景的「本機素材」匯入，存在這台裝置；伺服器上 `backgrounds/` 的圖從場景的「內建背景」選。

`user`（暱稱與頭像）**刻意設計成純前端 localStorage**、無後端端點；`voiceLang` 只是角色發聲語言的唯讀顯示，要改在「角色」頁。
